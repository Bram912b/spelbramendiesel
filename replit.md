# Project setup

This is a static p5.js creative-coding project.

## Run

Use the **Serve static** workflow (the Run button). It serves the project root and opens `index.html` in Replit Preview.

No dependency installation, environment variables, database, or secrets are required. The p5.js library is loaded from jsDelivr by `index.html`, so Preview needs internet access.

Edit `script.js` to change the sketch and refresh Preview to see updates.
